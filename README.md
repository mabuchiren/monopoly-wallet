# モノポリー銀行

プレイヤーが1人1台ずつスマホで開く、電卓型のモノポリー財布。

- テンキーで金額を打って「払う」「もらう」
- GO・所得税・物品税・保釈金はワンタップ
- 家賃（建物・独占・鉄道・公共会社）、土地、建物、抵当、修繕費、カード、全員とのやり取りを自動計算
- 残高不足の支払いは記録前に止める
- 履歴と取り消し。記録はブラウザの localStorage に保存（端末間の同期なし）

金額は現行の標準ルール（所得税 200 / 物品税 100 / 保釈金 50、抵当は半額・解除は +10%、建物の売却は半額）。

## 使い方

`index.html` をブラウザで開くだけ。ビルド不要。GitHub Pages で公開すればスマホから URL で開ける。
